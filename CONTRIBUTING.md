# Contributing to Block Buddies 🤝

> Building a sustainable, community-driven network for teaching CS through Minecraft.

Thank you for your interest in helping Block Buddies grow! Whether you're a parent, educator, tech enthusiast, community organizer, or even an AI assistant—there's a role for you here.

---

## 🌱 Core Philosophy

Block Buddies operates on these contribution principles:

1. **Mission First**: Every contribution should further our goal of connecting teen mentors with young learners
2. **Safety Always**: Changes must maintain or enhance our safety protocols
3. **Sustainable Growth**: We prefer slow, steady expansion over explosive but fragile growth
4. **Open Knowledge**: Curricula, methods, and learnings are shared openly
5. **Human-Centered**: Technology (including AI) serves humans, not the other way around

## 🔧 Contributing to Documentation

### Quick Edits

For typo fixes and small improvements:
1. Fork this repository
2. Make your changes
3. Submit a pull request with a clear description

### Major Changes

For new documents or significant restructuring:
1. **Open an issue first** describing what you want to add/change
2. Discuss with maintainers
3. Get approval before investing significant time
4. Submit a pull request

### Writing Guidelines

- Use clear, simple language (8th-grade reading level)
- Include examples wherever possible
- Consider all audiences (teens, parents, educators)
- Maintain consistent formatting with existing docs
- Test any technical instructions before documenting

## 🤖 For AI Agents & Assistants

AI contributions are welcome when they:

### ✅ DO

- Help draft or improve documentation
- Create curriculum materials following our "Cool Result First" pedagogy
- Analyze and organize feedback
- Generate ideas for lessons or activities
- Help with administrative tasks (scheduling templates, form generation)
- Assist with technical troubleshooting guides

### ⚠️ WITH CAUTION

- Suggesting changes to safety protocols (requires human review)
- Creating public-facing content (must be human-approved)
- Generating any materials involving minors

### ❌ DO NOT

- Make direct decisions about child safety
- Handle personal information about participants
- Make promises or commitments on behalf of Block Buddies
- Bypass human approval workflows
- Generate or modify consent forms without legal review

### AI Contribution Protocol

1. **Identify yourself**: Start contributions with a note that AI assisted
2. **Flag for human review**: Mark anything safety-related for explicit approval
3. **Respect boundaries**: Defer to human judgment on values-based decisions
4. **Document reasoning**: Explain why you're suggesting what you're suggesting

## 📊 Quality Standards

### For Curriculum Content

- [ ] Follows "Cool Result First" pedagogy
- [ ] Maps to CSTA K-12 standards where applicable
- [ ] Includes mentor notes/teaching tips
- [ ] Tested with actual sessions (or flagged as untested)
- [ ] Age-appropriate language

### For Program Documentation

- [ ] Clear audience identified
- [ ] Actionable guidance provided
- [ ] Consistent with existing docs
- [ ] Safety considerations addressed

### For Technical Content

- [ ] Tested on the platforms we support
- [ ] Includes troubleshooting steps
- [ ] Screenshots/examples where helpful
- [ ] Version-specific details noted
