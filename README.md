# Block Buddies 🎮

> Connecting teen mentors with younger kids through Minecraft modding and creative coding.

## The Concept

Block Buddies is a volunteer network where teens and preteens (ages 13-18) mentor younger children (ages 8-12) through **Minecraft modding**, teaching them foundational coding, problem-solving, and creative thinking skills.

### Why Minecraft Modding?

- **Low barrier to entry**: Kids already love Minecraft
- **Tangible results**: See your code come to life immediately
- **Creative freedom**: Build whatever you can imagine
- **Real programming**: Learn Java/JavaScript fundamentals through something fun
- **Community**: Millions of tutorials, mods, and examples to learn from
