# Pedagogy Quality Checklist

A lesson is releasable only if every item passes.

## Structure

- [ ] Runbook has required frontmatter fields
- [ ] Session loop follows Hook -> Example -> Core -> Side/Fallback -> Exit Ticket
- [ ] Early win occurs by minute 10
- [ ] Core quest and fallback are explicitly defined

## Learning Integrity

- [ ] Do/Explain/Debug gates are present
- [ ] Pass rule matches V2 policy
- [ ] At least one planned debug scenario exists
- [ ] Side quests are nested and optional, not replacements for core quest

## Safety and Accessibility

- [ ] 7-minute hard cap rule is explicitly stated
- [ ] Accessibility exception is documented
- [ ] No unsafe networking instruction for fluency 0

## Operational Readiness

- [ ] Session log fields are included
- [ ] Prerequisites are testable
- [ ] Artifacts and tool versions are specified
- [ ] Links to troubleshooting references are valid
