# Session Runbook Template (Required)

Use this template for every session runbook.

## Frontmatter Contract

```yaml
session_id: S00
track: core
fluency_range: 0-2
archetype: A/B/C
duration_minutes: 45
prerequisites:
  - prerequisite-1
mastery_gate_ids:
  - MG-S00-DO
  - MG-S00-EXPLAIN
  - MG-S00-DEBUG
fallback_path: One-line summary of fallback path
```

## Required Sections

1. **Objective**
   - One sentence: "By end of session, learner can ..."

2. **Loop Plan**
   - Hook (2-5 min)
   - Worked Example (5-8 min)
   - Core Quest (15-20 min)
   - Side Quest or Fallback (7-10 min)
   - Exit Ticket (3-5 min)

3. **Early Win**
   - Must occur in first 7-10 minutes

4. **Tier 1 Core Quest**
   - Exact steps
   - Expected output

5. **Tier 2 Stretch Side Quest**
   - Unlock rule
   - Outcome

6. **Tier 3 Expert Side Quest**
   - Unlock rule
   - Outcome

7. **Fallback Path**
   - Trigger condition
   - Mini-win activity

8. **Mastery Gates (Do/Explain/Debug)**
   - Do criterion
   - Explain criterion
   - Debug criterion
   - Pass/fail result

9. **Accessibility Notes**
   - Allowed shortcuts and when to use them

10. **Session Log Fields**
   - Fluency observed
   - Archetype observed
   - Time-cap events
   - Gate outcomes
   - Next session start condition
