# Pedagogy Engine V2

This file is the single source of truth for teaching rules across docs, mentor materials, and the website.

## Core Model

Block Buddies V2 uses **success-first learning** with **controlled friction**.

Every session follows one loop:

`Hook -> Worked Example -> Core Quest -> Side Quest or Fallback -> Exit Ticket`

## Canonical Rules

1. **Early win required**: first confidence win must happen by minute 10.
2. **Controlled friction limits**:
   - Fluency 0: intervene after 30 seconds of unproductive struggle.
   - Fluency 1: intervene after 2 minutes.
   - Fluency 2: intervene after 5 minutes.
3. **Hard cap**: if a learner is blocked for 7 minutes total on one task, use fallback path.
4. **Recovery ladder order is fixed**:
   - Guiding question
   - Specific hint
   - Model one step
   - Fallback mini-win
5. **Progressive disclosure is mandatory**:
   - Tier 1: Core Quest (everyone)
   - Tier 2: Stretch Side Quest
   - Tier 3: Expert Side Quest
6. **Mastery gate is Do/Explain/Debug**.
7. **Pass rule**: `Do=pass` and (`Explain=pass` or `Debug=pass`).
8. **If Debug fails**: next session begins with 5-minute debug retrieval.
9. **If Do fails**: repeat same session theme with lower scaffolding.
10. **Pacing**: session-index based and personalized; not calendar-locked.
11. **Accessibility exception**: GUI shortcuts are allowed for accessibility, safety, or time-cap breaches and must be logged.

## Progression Keys

- Fluency levels: `0`, `1`, `2`
- Archetypes: `A` (Visualist), `B` (Mechanist), `C` (Operator)
- Track IDs: `core`, `visualist`, `mechanist`, `operator`

## Canonical Session Matrix

1. Session 1: Diagnostic, trust, first guaranteed win
2. Session 2: Core safety/backups and controlled failure recovery
3. Session 3: Track onboarding + stretch branch
4. Session 4: Track foundation build + debug drill
5. Session 5: Track extension + side-quest unlocks
6. Session 6: Troubleshooting studio
7. Session 7: Capstone build + mentor fade
8. Session 8: Demo, reflection, mastery verification, continuation

## Required Artifacts For Each Session

- Runbook with frontmatter contract
- Mastery gates
- Side-quest unlock logic
- Fallback path
- Exit ticket
- Session log entry
