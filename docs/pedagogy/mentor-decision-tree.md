# Mentor Decision Tree

> **LEGACY PATHWAY (superseded by V3 canon, 2026-08-23):** This document describes the retired V2 fluency-archetype model (tracks, S01-S08 spine, Do/Explain/Debug). It is preserved for the advanced pathway and historical reference only. For current truth see [Product & Pedagogy Canon](../canon/product-canon.md) or [Canon](../canon/product-canon.md).

Use this decision tree during any block or confusion event.

## Inputs

- Fluency level (`0/1/2`)
- Time blocked on current task
- Emotional state (calm / frustrated / disengaged)

## Decision Flow

1. **Check time vs fluency limit**
   - L0 > 30s -> intervene
   - L1 > 2m -> intervene
   - L2 > 5m -> intervene
2. **Run recovery ladder in order**
   - Guiding question
   - Specific hint
   - Model one step
   - Fallback mini-win
3. **If total block time >= 7m**
   - Stop current task
   - Switch to fallback path
   - Log time-cap event
4. **If emotional disengagement detected**
   - Apply reset (short break or confidence micro-win)
   - Resume at simpler step

## Fallback Rules

- Fallback must still reinforce the same objective family.
- Fallback cannot be pure entertainment.
- Fallback must end with a visible success artifact.

## Scaffolding Shift Rules

- If repeated confusion: shift down one scaffolding level.
- If early completion and clear explanation: unlock stretch or expert side quest.

## Required Logging

Log all time-cap and fallback events in session notes.
