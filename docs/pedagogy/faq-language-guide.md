# Language Guide: Internal vs External

## Policy

- Internal mentor docs may reference "Trojan Horse" as a shorthand.
- Public-facing pages should use family-friendly framing:
  - "interest-first"
  - "game-based"
  - "confidence-first"

## Public Copy Rules

Use:
- "Minecraft-powered, real-world tech learning"
- "Hands-on computer science through guided projects"
- "Confidence-first learning with structured support"

Avoid:
- "cynical"
- "we engineer failure"
- "for babies"
- adversarial framing of learners or other educational tools

## Internal Copy Rules

Allowed in mentor documents:
- "Trojan Horse concept" when mapped to explicit outcomes
- "controlled friction" with time caps and fallback rules

Required in all contexts:
- Respectful language
- Safety-first language
- Clear boundaries and escalation wording
