# Mentorship Program Structure

## Overview

The Block Buddies mentorship model pairs one teen mentor with one younger kid (1:1) for a structured program of weekly video calls focused on Minecraft modding and basic coding concepts.

---

## Program Structure

### Program Cycle

```
┌─────────────────────────────────────────────────────────────┐
│  COHORT MODEL (8-12 weeks)                                  │
├─────────────────────────────────────────────────────────────┤
│  Week 0    │ Mentor training, matching, parent intros       │
│  Week 1    │ Meet & greet, assess skill level, set goals    │
│  Week 2-3  │ Module 1: Basics                               │
│  Week 4-5  │ Module 2: Intermediate                         │
│  Week 6-7  │ Module 3: Creation                             │
│  Week 8    │ Capstone project work                          │
│  Week 9+   │ Showcase, celebration, optional continuation   │
└─────────────────────────────────────────────────────────────┘
```

### Why Cohort Model?

- Clear start and end creates commitment
- Mentors know the time investment upfront
- Natural breaks for mentor turnover
- Celebrates completions together
- Easier to manage and evaluate

## The Matching Process

### Information Collected

**From Mentees (via parent):**
- Age
- Minecraft experience level
- What they want to learn/build
- Availability
- Learning style (if known)
- Any accessibility needs

**From Teen Mentors:**
- Age/grade
- Minecraft modding experience level
- What they're excited to teach
- Availability
- Teaching/tutoring experience (if any)
- Why they want to mentor

### Matching Criteria (in priority order)

1. **Availability alignment** - Overlapping free times
2. **Timezone compatibility** - Within 2 hours
3. **Skill level match** - Mentor should be 2+ levels above mentee
4. **Interest alignment** - Building vs. coding vs. design focus
5. **Personality indicators** - If we can assess them

### Trial Period

- First session is a "trial"
- Either party can request a rematch after trial
- No questions asked, no blame

## Session Structure

### Recommended Format (45 minutes)

| Time | Activity |
|------|----------|
| 0:00 - 0:05 | Warm-up chat, check in on homework/practice |
| 0:05 - 0:10 | Review: What did we learn last time? |
| 0:10 - 0:35 | Main lesson + hands-on practice |
| 0:35 - 0:40 | Wrap-up: What did we accomplish? |
| 0:40 - 0:45 | Preview next session, assign practice |

### Session Cadence

- **Recommended**: Weekly, same day/time
- **Minimum**: Bi-weekly
- **Maximum gap**: 2 weeks (longer = loss of momentum)

### Cancellation Policy

- 24 hours notice preferred
- Life happens - but pattern of cancellations → check-in with coordinator
- 2 no-shows without notice → mentorship paused for conversation

## Mentor Support System

### Training (Before First Session)

1. **Safety & guidelines** (30 min video + quiz)
2. **How to teach** (30 min video + tips)
3. **Tech walkthrough** (setup guide + troubleshooting)
4. **Curriculum overview** (what you'll be teaching)
5. **Mock session** (practice with another teen or coordinator)

### Ongoing Support

- **Mentor Slack/Discord channel**: Ask questions, share wins, troubleshoot
- **Weekly office hours**: Coordinator available for questions
- **Peer mentoring**: Experienced mentors help new ones
- **Resource library**: Lesson plans, activities, troubleshooting guides

### Recognition

- Certificates of completion
- Volunteer hour documentation
- LinkedIn recommendation (for older teens)
- Showcase event participation
- "Mentor of the Month" recognition

## Quality Assurance

### Feedback Loops

- **After each session**: Quick emoji rating from mentee
- **Mid-program**: Parent + mentee check-in survey
- **End of program**: Detailed feedback from all parties
- **Mentor self-reflection**: After each session

### Coordinator Check-ins

- Watch recording snippets (sample 5-10 min)
- Reach out to struggling pairs proactively
- Celebrate strong pairs

### Success Indicators

- Session attendance rate
- Mentee progress on learning goals
- Parent satisfaction
- Mentor satisfaction
- Completion rate

---

## Edge Cases & Exceptions

### What if the mentee is way behind/ahead?

- Adjust curriculum pace
- If severe mismatch, consider different mentor with different skill level

### What if the mentor is struggling?

- Extra coaching from coordinator
- Pair with experienced mentor for tips
- Reduce session frequency temporarily
- Last resort: transition to different mentor

### What if they want to continue after program ends?

- Great! Can re-enroll for next module
- Same pair if both want
- Possibility of advancing to more complex projects

### What about group sessions?

- Future possibility: 1 mentor, 2-3 mentees
- More efficient but harder to manage
- Would need different training/curriculum
