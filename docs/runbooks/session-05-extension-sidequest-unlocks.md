# Session 5: Extension Task and Side-Quest Unlocks

## Objective
Learner extends prior build with one new capability and demonstrates independent decision making.

## Loop Plan
- Hook (5m): showcase upgraded version.
- Worked Example (5m): mentor adds one extension quickly.
- Core Quest (20m): learner adds required extension.
- Side Quest or Fallback (10m): unlock stretch/expert or simplify.
- Exit Ticket (5m): learner picks next improvement path.

## Early Win
Existing build from Session 4 is loaded and verified immediately.

## Tier 1 Core Quest
Add one extension:
- A: second texture family or shader tweak.
- B: repeaters/timing control or SU budget change.
- C: second permission tier or whitelist rule.

## Tier 2 Stretch Side Quest
- Unlock: Fluency >= 1 and MG-S04-DEBUG pass
- Outcome: integrate one cross-concept dependency.

## Tier 3 Expert Side Quest
- Unlock: Fluency = 2 and MG-S05-DO pass
- Outcome: design and run own test checklist.

## Fallback Path
Constrain to single variable change and immediate verification loop.

## Mastery Gates
- Do: extension works in live test.
- Explain: learner predicts effect before applying change.
- Debug: learner reverts unsafe change and restores working state.
