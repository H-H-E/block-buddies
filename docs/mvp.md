# MVP Definition (V2)

> **LEGACY PATHWAY (superseded by V3 canon, 2026-08-23):** This document describes the retired V2 fluency-archetype model (tracks, S01-S08 spine, Do/Explain/Debug). It is preserved for the advanced pathway and historical reference only. For current truth see [Product & Pedagogy Canon](./canon/product-canon.md) or [Canon](./canon/product-canon.md).

## MVP Goal

Run one 8-session cohort with personalized pacing and full V2 pedagogy compliance.

## In Scope

- Diagnostic profile coding (`fluency-archetype`)
- 8 canonical session runbooks
- Core + track pathway execution
- Do/Explain/Debug session logging
- Safety, consent, and escalation process

## Before Launch Checklist

### People
- [ ] 1 coordinator
- [ ] 3-5 mentors + 1-2 backups
- [ ] 3-5 mentee families

### Pedagogy Artifacts
- [ ] Engine V2 published
- [ ] Session template published
- [ ] Mastery rubric published
- [ ] S01-S08 runbooks published
- [ ] Session log template in use

### Program Ops
- [ ] Matching process uses profile code
- [ ] Matching process records profile confidence and reassessment flags
- [ ] Mentor onboarding includes controlled friction rules
- [ ] Tech stack selected and tested
- [ ] Incident and concern escalation path documented

### Validation
- [ ] Every pilot pair completed S01 and S02 with logs
- [ ] At least one track path trialed end-to-end
- [ ] Runbook schema and link checks pass
- [ ] Reassessment/rematch workflow tested once end-to-end

## MVP Success Criteria

- No safety incidents
- >= 60% cohort completion
- >= 70% session pass rate
- Families and mentors report clarity in expectations
