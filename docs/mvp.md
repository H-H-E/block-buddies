# MVP Definition

## What is the Minimum Viable Block Buddies?

The smallest version that lets us:
1. Match 3-5 teen mentors with 3-5 younger kids
2. Run a single 8-week cohort
3. Validate that the model works (or learn why it doesn't)

---

## MVP Scope

### ✅ In Scope

| Component | MVP Version |
|-----------|-------------|
| **Matching** | Manual (spreadsheet + human judgment) |
| **Scheduling** | Email coordination or simple tool (Calendly) |
| **Video calls** | Zoom or Google Meet (free tier) |
| **Curriculum** | 5-6 pre-written lesson plans |
| **Safety** | Written guidelines, parental consent |
| **Resources** | Google Drive folder with materials |
| **Communication** | Email list or group chat (WhatsApp/Slack) |
| **Tracking** | Simple spreadsheet for attendance/notes |

### ❌ Out of Scope (for now)

- Custom website with login
- Automated matching
- Integrated scheduling
- Video call recording storage
- Progress tracking dashboard
- Formal certificates
- Multiple concurrent cohorts

---

## What We Need Before Launch

### 👥 People

- [ ] **3-5 teen mentors** recruited and committed
- [ ] **3-5 mentee families** signed up
- [ ] **1 coordinator** (could be you!) to facilitate

### 📄 Documents

- [ ] **Safety guidelines** - what's expected, what's not allowed
- [ ] **Parental consent forms** - for both mentors and mentees
- [ ] **Mentor expectations doc** - what they're signing up for
- [ ] **Curriculum** - at least 6 session plans covering 8 weeks

### 🔧 Tools (free/cheap)

- [ ] **Video conferencing** - Zoom free, Google Meet, or Jitsi
- [ ] **Scheduling** - Calendly, When2Meet, or manual
- [ ] **File storage** - Google Drive for all resources
- [ ] **Communication** - Email or free Slack/Discord
- [ ] **Tracking** - Google Sheets

### 📚 Resources

- [ ] **Setup guides** - getting Minecraft/mods working
- [ ] **Lesson plans** - step-by-step for each session
- [ ] **Troubleshooting doc** - common problems and fixes

---

## Launch Criteria

We're ready to start when:

- [ ] At least 3 matched pairs confirmed
- [ ] All consent forms signed
- [ ] All mentors completed training materials
- [ ] First session dates scheduled
- [ ] Tech tested (video calls work, Minecraft runs)
- [ ] Emergency contact list compiled
- [ ] Clear process for feedback and concerns

---

## MVP Timeline

```
Week -4: Finalize materials
Week -3: Recruit mentors
Week -2: Recruit mentees, match pairs
Week -1: Tech setup, intro calls
Week 1-8: Program runs
Week 9: Collect feedback, celebrate
Week 10: Retrospective, plan next steps
```

---

## Success Criteria for MVP

### Quantitative
- **Completion rate**: >60% of pairs finish all 8 weeks
- **Attendance**: >80% of scheduled sessions happen
- **No safety incidents**

### Qualitative
- Mentees: Learned something new, had fun
- Mentors: Would recommend to a friend
- Parents: Would sign up again

### Learning Goals
- What worked in the curriculum?
- What scheduling challenges arose?
- How much coordinator time was needed?
- What safety concerns came up?
- Would a simpler curriculum work better?

## Risks Specific to MVP

| Risk | Mitigation |
|------|------------|
| Can't find enough mentors | Start with personal network, local schools |
| Can't find enough mentees | Partner with one school or organization |
| Mentor drops out | Have 1-2 backup mentors on standby |
| Technical disaster | Pre-session tech check, backup lesson plan that doesn't require Minecraft |
| Parent concerns | Over-communicate, be responsive, have coordinator present for first sessions |

---

## Post-MVP Decision Points

After the first cohort, decide:

1. **Scale up?** If yes, what needs to improve first?
2. **Pivot?** What should change about the model?
3. **Stop?** Did we learn this doesn't work?

Key questions to answer:
- Was this worth the coordinator's time?
- Is there organic demand (people wanting to join)?
- What's the realistic path to scale?
- Do we need funding/partners to continue?
