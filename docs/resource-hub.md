# Resource Hub Plan (V2)

## Purpose

Provide a single place for mentors, families, and learners to access aligned V2 materials.

## Information Architecture

### Public Layer
- Program overview
- Safety and trust FAQs
- Curriculum overview (family-friendly language)
- Application links

### Mentor Layer
- Session runbooks (S01-S08)
- Troubleshooting atlas
- Session log templates
- Mentor decision tree

### Coordinator Layer
- Matching guide
- Escalation protocol
- Metrics dashboard template

## Phase 1 (Launch Minimum)

- [ ] Public curriculum overview synced with V2
- [ ] Mentor runbook index available
- [ ] Session log template and examples
- [ ] FAQ language aligned with external style guide

## Phase 2

- [ ] Searchable troubleshooting catalog
- [ ] Track-specific capstone exemplars
- [ ] Mentor calibration videos

## Phase 3

- [ ] Analytics dashboards for pass/fallback trends
- [ ] Program-level impact reporting
