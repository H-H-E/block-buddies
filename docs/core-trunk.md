# Core Trunk (V2)

> **LEGACY PATHWAY (superseded by V3 canon, 2026-08-23):** This document describes the retired V2 fluency-archetype model (tracks, S01-S08 spine, Do/Explain/Debug). It is preserved for the advanced pathway and historical reference only. For current truth see [Product & Pedagogy Canon](./canon/product-canon.md) or [Canon](./canon/product-canon.md).

All learners complete Core before deeper track specialization.

## Core Sessions

- **S01** Diagnostic + first win
- **S02** Safety, backup, and recovery

See canonical runbooks:
- [S01](./runbooks/session-01-diagnostic-trust-win.md)
- [S02](./runbooks/session-02-safety-backups-recovery.md)

## Core Outcomes

By end of Core, learner can:

- Navigate to Minecraft data folder with profile-appropriate support
- Distinguish file name vs extension
- Create and restore named backups
- Perform one basic debug correction
- Explain one safety rule for downloads/configuration

## Core Session Artifacts

- S01:
  - first-win file present
  - `fluency-archetype` + confidence recorded
  - one evidence note for fluency and archetype
- S02:
  - named backup archive exists
  - controlled restore completed
  - backup naming rationale captured

## Core Mastery Gate Expectations

| Gate | Minimum pass signal |
|---|---|
| Do | completes backup and one controlled edit task |
| Explain | describes why save/restore sequence matters |
| Debug | fixes one seeded error with prompts |

## Core-to-Track Promotion Rule

Promote only if Core Do passes and at least one of Explain/Debug passes.

If S02 Debug fails, S03 begins with a 5-minute debug retrieval before onboarding.
