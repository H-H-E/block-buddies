# Contributor Types (V2)

## Purpose

Clarify who contributes what, and where V2 quality gates apply.

## Roles

### Educators / Curriculum Designers
- Maintain runbooks and mastery gates
- Review side-quest unlock logic
- Validate age-appropriate language

### Teen Mentor Leads
- Pilot runbooks
- Report fallback/time-cap events
- Suggest improvements based on session logs

### Tech Volunteers
- Maintain curriculum data model in code
- Keep website copy aligned with canonical docs
- Build validation tests for runbook/frontmatter consistency

### Parent/Guardian Advisors
- Review clarity and trust language
- Validate onboarding and safety communications

### Community Organizers
- Recruit mentors and families
- Coordinate scheduling and operations

### AI Assistants
- Draft docs and formatting updates
- Propose structured rewrites
- Must flag assumptions and request human review

## V2 Review Checklist For Any Role

- [ ] Consistent with Pedagogy Engine V2
- [ ] No contradiction with session matrix or mastery pass rules
- [ ] Public language remains confidence-first
- [ ] Safety boundaries are intact
