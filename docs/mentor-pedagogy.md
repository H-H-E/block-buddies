# Mentor Pedagogy (V2)

## Mission

Guide discovery without leaving learners stuck. V2 replaces unbounded struggle with **controlled friction** and clear fallback logic.

## Non-Negotiables

1. Deliver an early win in first 10 minutes.
2. Follow session loop contract exactly.
3. Use recovery ladder in order.
4. Respect 7-minute hard cap for blocked tasks.
5. Score Do/Explain/Debug every session.
6. Log accessibility shortcuts and fallback events.

## Recovery Ladder

1. Guiding question
2. Specific hint
3. Model one step
4. Fallback mini-win

Do not skip steps unless safety or accessibility requires immediate intervention.

## Intervention Timing By Fluency

| Fluency | Intervention trigger |
|---|---|
| 0 | 30 seconds |
| 1 | 2 minutes |
| 2 | 5 minutes |

## Hard-Cap Rule

If blocked on one task for 7 minutes total:
- stop the task
- switch to fallback path
- capture a mini-win
- log event

## Scaffolding Modes

- **Model**: mentor demonstrates
- **Guide**: mentor prompts while learner executes
- **Fade**: learner executes, mentor observes
- **Independent**: learner executes and self-checks

Use lower mode when Do fails. Use higher mode only after repeated stable passes.

## Mastery Gate Protocol

At session end, record:
- Do
- Explain
- Debug

Pass if Do and one of Explain/Debug pass.

## Communication Style

Use precise, calm, respectful language.

Public-facing and parent-facing language should remain confidence-first and family-friendly.
