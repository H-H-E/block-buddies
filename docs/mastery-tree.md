# Block Buddies Mastery Tree (V2)

> Internal curriculum architecture for mentors, curriculum contributors, and operators.

## Executive Summary

Block Buddies V2 keeps the Mastery Tree + Core/Tracks architecture and upgrades delivery with a single engine:

- Success-first starts
- Controlled friction
- Do/Explain/Debug mastery gates
- Progressive side-quest disclosure
- Personalized pacing by session index

Canonical policy lives in [Pedagogy Engine V2](./pedagogy/engine-v2.md).

## Architecture

1. **Diagnostic Protocol** -> profile code (`fluency-archetype`)
2. **Core Trunk** -> universal safety and systems baseline
3. **Specialization Track**
   - A Visualist
   - B Mechanist
   - C Operator
4. **Capstone + Verification**

## Session Matrix (Canonical)

| Session | Focus | Universal Requirement |
|---|---|---|
| S01 | Diagnostic + trust + first win | profile code captured |
| S02 | Backups + controlled recovery | backup/restore completed |
| S03 | Track onboarding | starter artifact works |
| S04 | Foundation + debug drill | one seeded fault fixed |
| S05 | Extension | one capability extension works |
| S06 | Troubleshooting studio | root cause + fix evidence |
| S07 | Capstone build | mentor fade + independent steps |
| S08 | Demo + reflection | mastery verification complete |

## Learning Mechanics

### Fixed Session Loop
`Hook -> Worked Example -> Core Quest -> Side Quest/Fallback -> Exit Ticket`

### Controlled Friction Rules
- L0 intervene after 30s
- L1 intervene after 2m
- L2 intervene after 5m
- Hard cap at 7m blocked time for any task

### Progressive Disclosure
- Tier 1: core quest (required)
- Tier 2: stretch side quest (conditional)
- Tier 3: expert side quest (conditional)

### Mastery Gate
Session passes when `Do` passes and at least one of `Explain` or `Debug` passes.

## Internal Pedagogical Framing

Internal mentor shorthand may reference "Trojan Horse" as a concept bridge. Public pages use confidence-first, family-friendly wording.
