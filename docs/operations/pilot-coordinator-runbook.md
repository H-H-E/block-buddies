# Pilot Coordinator Runbook (Week-by-Week)

## Week 0: Setup

- Confirm mentor roster and backups.
- Validate mentee intake completeness.
- Complete pairing quick-view template.
- Verify consent/safety readiness.

## Week 1-2: Launch (S01-S02)

- Monitor profile confidence and reassessment flags.
- Verify Do/Explain/Debug logs are submitted for each session.
- Trigger support for any 7-minute hard-cap hotspots.

## Week 3-6: Progression (S03-S06)

- Review fallback-rate trends per pair.
- Review mentor mismatch signals.
- Trigger reassessment/rematch workflow when needed.

## Week 7-8: Verification (S07-S08)

- Confirm capstone/demo evidence completeness.
- Confirm final mastery logs are complete.
- Collect parent/mentor clarity feedback.

## Weekly Operations Cadence

1. Monday: review prior week logs.
2. Tuesday-Wednesday: resolve mismatches/escalations.
3. Thursday-Friday: confirm upcoming session readiness.
4. Weekend: compile weekly summary.
