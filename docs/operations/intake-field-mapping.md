# Intake Field-to-Operations Mapping (V2)

> **LEGACY PATHWAY (superseded by V3 canon, 2026-08-23):** This document describes the retired V2 fluency-archetype model (tracks, S01-S08 spine, Do/Explain/Debug). It is preserved for the advanced pathway and historical reference only. For current truth see [Product & Pedagogy Canon](../canon/product-canon.md) or [Canon](../canon/product-canon.md).

This mapping is the canonical handoff between intake forms and coordinator decisions.

## Mentee Intake Contract

| Field | Required | Operational use |
|---|---|---|
| child name/age | Yes | eligibility and roster planning |
| parent contact | Yes | consent, scheduling, escalation contact |
| fluency level (`0/1/2`) | Yes | scaffold depth + mentor fit |
| archetype preference (`A/B/C`) | Yes | track-aligned mentor matching |
| profile confidence (`high/medium/low`) | Yes | reassessment priority |
| accessibility notes | Yes | accommodation plan and mentor prep |
| learning goals | Yes | session examples and motivation framing |
| availability | Yes | pairing and session scheduling |
| setup/consent confirmations | Yes | launch readiness and safety compliance |

## Mentor Intake Contract

| Field | Required | Operational use |
|---|---|---|
| identity + age + parent approval | Yes | eligibility and guardian visibility |
| experience profile | Yes | training needs and track fit |
| preferred track | Yes | primary placement |
| supported fluency levels | Yes | compatibility with mentee scaffold range |
| availability | Yes | pairing constraints |
| code of conduct | Yes | safety gate |
| mastery logging agreement | Yes | quality control gate |
| mismatch escalation agreement | Yes | reassessment/rematch workflow |
| commitment agreement | Yes | cohort reliability |

## Mandatory Read-Before-Match Fields

1. Mentee profile code (`fluency-archetype`).
2. Mentee profile confidence.
3. Mentee accessibility notes.
4. Mentor supported fluency levels.
5. Mentor mismatch escalation agreement.
6. Availability overlap confirmation.
