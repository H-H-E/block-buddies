# Mentor Calibration Protocol

## Goal

Keep mentor delivery consistent with V2 policy across all pairs.

## Minimum Calibration (biweekly)

1. 20-minute runbook walkthrough (one session index).
2. 20-minute log review (Do/Explain/Debug + fallback events).
3. 10-minute mismatch/reassessment case review.

## Calibration Checklist

- [ ] Session loop order followed.
- [ ] Intervention timing respected by fluency.
- [ ] 7-minute hard cap and fallback used correctly.
- [ ] Pass rule applied correctly.
- [ ] Next-session condition logged.

## Corrective Actions

- If repeated loop drift: assign focused retraining.
- If logging drift: assign one-session shadow review.
- If mismatch misses: coordinator approval required before next session.
