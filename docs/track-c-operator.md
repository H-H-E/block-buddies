For learners motivated by server rules, reliability, and administration.

## Session Alignment (after Core)

| Session | Core Quest | Stretch Side Quest | Expert Side Quest |
|---|---|---|---|
| S03 | edit and verify starter server config | add one policy setting | configure from memory |
| S04 | resolve connection/config fault | add second access rule | binary-search network/config issue |
| S05 | extend role/permission model | add least-privilege hardening | produce own validation plan |
| S06 | solve network or ACL failure | eliminate false causes with evidence | run full diagnosis loop independently |
| S07 | capstone admin setup slice | add backup or monitoring step | self-run mastery rubric |
| S08 | demo + reflection | incident-retrospective walkthrough | define next operations roadmap |

## Operator Mastery Signals

- Do: working server/admin behavior
- Explain: clear IP/port/permission reasoning
- Debug: can recover one seeded operations fault

## Operator Evidence Checklist

- [ ] Config diff or key/value proof captured each session.
- [ ] One safety/rollback note captured in S04+.
