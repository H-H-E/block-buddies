# Diagnostic Protocol (V2)

## Goal

Place each learner on the right scaffolding level and track entry point within 5 minutes, then validate with a first-win task.

## Output

- Fluency: `0`, `1`, or `2`
- Archetype: `A`, `B`, or `C`
- Profile code: `fluency-archetype` (for example `2-C`)

## Diagnostic Tasks

### Task 1: File Navigation
Prompt: create folder `BlockBuddies` and move a named file into it.

### Task 2: Minecraft Folder Orientation
Prompt: show where Minecraft stores local data.

### Task 3: Motivation Probe
Prompt: pick preferred challenge:
- A visual redesign
- An automation machine
- A server with roles/rules

## Fluency Classification

| Level | Signal |
|---|---|
| 0 | cannot reliably navigate files without step-by-step prompting |
| 1 | can navigate with some prompting and basic confidence |
| 2 | navigates quickly, can explain path logic, tolerates debugging |

## Archetype Classification

| Archetype | Signal |
|---|---|
| A | prefers visual customization |
| B | prefers optimization/automation |
| C | prefers control/multiplayer administration |

## Early Win Requirement

By minute 10, learner must complete one visible success action (for confidence anchoring).

## Recording Template

- Mentee name
- Date
- Fluency level
- Archetype
- Profile code
- Accessibility notes
- Starting session

## Reassessment Rules

- Recheck profile every 2-3 sessions
- Update fluency when skill evidence changes
- Allow archetype shift when motivation changes
