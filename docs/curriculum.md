# Curriculum Ideas

## The Dynamic, Nested Curriculum Matrix

Block Buddies uses a **Decision Tree** approach rather than a linear path. A rigid curriculum fails when facing the variable baselines of modern digital literacy.

### Curriculum Entry Process

```
┌─────────────────────────────────────────────────────────────┐
│  STEP 1: Diagnostic Protocol ("The Sorting Hat")            │
│  → 5-minute assessment to determine Tech Fluency & Archetype│
│  → See: diagnostic-protocol.md                              │
├─────────────────────────────────────────────────────────────┤
│  STEP 2: Core Trunk (Universal Skills)                      │
│  → File Systems, Backups, Digital Safety                    │
│  → All students complete before specialization              │
│  → See: core-trunk.md                                       │
├─────────────────────────────────────────────────────────────┤
│  STEP 3: Specialization Track (Based on Archetype)          │
│  → Track A: Visualist (Builders) - Resource Packs, Shaders  │
│  → Track B: Mechanist (Engineers) - Redstone, Create Mod    │
│  → Track C: Operator (Admins) - Servers, Permissions        │
└─────────────────────────────────────────────────────────────┘
```

### Tech Fluency Levels

| Level | Profile | Instructional Strategy |
|-------|---------|----------------------|
| **0** | iPad Native | Heavy scaffolding, 80% on OS navigation |
| **1** | Gamer | Bridge building, consumer → creator |
| **2** | Tinkerer | Challenge mode, focus on "why" |

### Archetype Specializations

| Code | Profile | Entry Point |
|------|---------|-------------|
| **A** | Visualist | Resource Packs, Shaders |
| **B** | Mechanist | Redstone, Create Mod |
| **C** | Operator | Server Config, Permissions |

For detailed assessment, see [Diagnostic Protocol](diagnostic-protocol.md).

## Philosophy

> **"Build first, explain later"**



Kids learn best by DOING, then understanding WHY. Every session should have them creating something, not just listening.

## Learning Paths

### Path A: Creative Builder (No Code)
*For: Kids who love building but aren't ready for code*

```
Module 1: Resource Pack Basics
  └── Custom textures
  └── Custom sounds
  └── Sharing your pack

Module 2: Command Block Magic
  └── Basic commands
  └── Command block chains
  └── Mini-games with commands

Module 3: Datapacks
  └── Custom recipes
  └── Custom advancements
  └── Simple loot tables
```

### Path B: Beginner Coder
*For: Kids ready to write some code*

```
Module 1: Coding Foundations (via Minecraft)
  └── What is code?
  └── Variables (scoreboard = variable!)
  └── If/then logic (command blocks)

Module 2: MakeCode for Minecraft (if using Education Edition)
  └── Block-based coding
  └── Creating agents
  └── Automating builds

Module 3: Introduction to Java
  └── Setting up the environment
  └── "Hello World" mod
  └── Custom items
```

### Path C: Aspiring Modder
*For: Kids with some coding background*

```
Module 1: Environment Setup
  └── Java basics
  └── IDE (IntelliJ, Eclipse)
  └── Forge/Fabric setup

Module 2: First Real Mod
  └── Custom items
  └── Custom blocks
  └── Crafting recipes

Module 3: Advanced Features
  └── Custom mobs
  └── World generation
  └── GUIs
```

## Sample Session Plans

### Session: "Make a Custom Texture"

**Goal**: Replace an existing Minecraft texture with their own art

**Materials needed**:
- Any image editor (even MS Paint)
- Template files (provided)
- Minecraft installed

**Lesson plan**:

| Time | Activity |
|------|----------|
| 5 min | Show examples of cool resource packs to inspire |
| 5 min | Explain how textures work (folder structure) |
| 20 min | Together: retexture one item (diamond sword → lightsaber?) |
| 10 min | Solo practice: pick another item to retexture |
| 5 min | Test in game, celebrate! |

**Homework**: Retexture 3 more items before next session

---

### Session: "Command Block Basics"

**Goal**: Create a teleportation button using command blocks

**Materials needed**:
- Minecraft Creative mode
- Cheats enabled

**Lesson plan**:

| Time | Activity |
|------|----------|
| 5 min | Demo: show a cool command block creation |
| 10 min | Explain commands: /tp, /give, /effect |
| 20 min | Build together: teleport pad |
| 5 min | Challenge: add a cool particle effect |
| 5 min | Discuss: what else could we make? |

**Homework**: Make a command block that gives you an item

---

### Session: "Hello World Mod"

**Goal**: Create a mod that adds a single custom item

**Materials needed**:
- Development environment set up (done in prep)
- Template project

**Lesson plan**:

| Time | Activity |
|------|----------|
| 5 min | Recap: what is a mod vs texture pack? |
| 10 min | Tour the project structure |
| 20 min | Follow along: create custom item |
| 5 min | Run and test (exciting moment!) |
| 5 min | Brainstorm: what item for next time? |

**Homework**: Sketch out your dream custom item

## Capstone Project Ideas

### Beginner (No Code)
- Complete resource pack that "reskins" Minecraft to a theme (underwater, space, medieval)
- Mini-game using command blocks
- Adventure map with custom elements

### Intermediate
- Datapack that adds a new game mechanic
- MakeCode project that automates a complex build
- Tutorial video teaching what you learned

### Advanced
- Full mod with 5+ custom items/blocks
- Mod that solves a "problem" in Minecraft
- Contribution to an existing open-source mod

## Assessment & Progress Tracking

### Skill Checkpoints

**Beginner Creative**:
- [ ] Can navigate Minecraft resource pack folders
- [ ] Can edit and replace a texture
- [ ] Understands file formats (PNG dimensions, etc.)

**Beginner Coding**:
- [ ] Understands what variables are
- [ ] Can read and explain simple code logic
- [ ] Can make small changes to existing code

**Intermediate**:
- [ ] Can set up development environment with help
- [ ] Can create basic mod from template
- [ ] Understands debugging (read error messages)

**Advanced**:
- [ ] Can set up environment independently
- [ ] Can create custom features without templates
- [ ] Can troubleshoot common issues
